# Easel + Vanilla TypeScript

A minimal Shopify Liquid theme using Easel, TypeScript, CSS, and no frontend framework. It demonstrates named bundles, a dynamic import, and Vite-managed image and font assets.

```sh
npm install
npm run dev
shopify theme dev --notify .easel/shopify-ready
```

Build before pushing or packaging:

```sh
npm run build
shopify theme push
```
