# Security policy

## Supported versions

Security fixes are applied to the latest stable releases of `vite-plugin-shopify-easel` and `create-easel-theme`.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use [GitHub private vulnerability reporting](https://github.com/BillyNoyes/Easel/security/advisories/new) and include:

- the affected package and version;
- the operating system and Node.js version;
- a minimal reproduction;
- the expected and observed behavior;
- the potential impact.

Do not include npm credentials, Shopify credentials, store tokens, customer data, or other secrets. You should receive an initial response within seven days. Confirmed issues will be coordinated privately until a fix and disclosure plan are ready.
