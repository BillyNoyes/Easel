# **THEME_NAME**

A framework-neutral Shopify theme scaffold powered by Frame and Vite.

## Development

From the Frame repository root:

1. Run `pnpm install`.
2. Run `pnpm --dir PATH_TO_THEME dev`.
3. In another terminal, run `shopify theme dev --path PATH_TO_THEME --notify PATH_TO_THEME/.frame/shopify-ready`.

Run `pnpm --dir PATH_TO_THEME check` before publishing.
